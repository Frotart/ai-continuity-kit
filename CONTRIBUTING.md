# Contributing

Thanks for helping improve the kit. It gets better from real use, so the most
useful contributions are reports of where it didn't fit.

## The quickest ways to help

- **Report a friction.** Something unclear, a rule that slowed you down, an
  assistant that misread a file. Use the
  [friction report](https://github.com/Frotart/ai-continuity-kit/issues/new?template=friction.md).
  Small ones count.
- **Share an adaptation.** If you've changed the kit for a different workflow,
  tool or team size, tell us what you changed and why with the
  [adaptation template](https://github.com/Frotart/ai-continuity-kit/issues/new?template=adaptation.md).
- **Star the repository** if it helps you; it helps others find it.

## Pull requests

1. Open an issue first for anything bigger than a typo, so we can agree the
   change before you write it.
2. Keep every example **synthetic**. Never include real names, businesses,
   amounts, credentials or content from your own knowledge repository.
3. Follow the kit's own rules: plain language, evidence labels where a claim
   is made, and one idea per change.
4. Add a line to [CHANGELOG.md](CHANGELOG.md) under the next version, with the
   lesson that prompted the change.

## What fits the kit

The kit stays small on purpose: Markdown files, no installs, no services.
Proposals that add a required tool, a database or automatic capture are out of
scope; optional notes on how to pair the kit with a tool are welcome.

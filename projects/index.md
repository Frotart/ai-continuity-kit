replace them.

Keep project IDs stable: don't renumber or reuse them, even when a project
closes. An index-only entry (no master file yet) is not permission to access
that project's data.

Open the project's `overview.md`, then its `status.md`, at the current Git
revision. Original data stays in each project's folder in the data repository.
